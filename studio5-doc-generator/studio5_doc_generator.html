Proforma Invoice / Invoice — Nested BOQ Item Format

Use this when one work description covers several priced components (e.g. a room-furniture package). Confirmed final format:

Sr. No.ParticularsUOMQty/AreaRateNo. of RoomsAmount
1Providing and fixing [description] — spans full width, bold
aComponent 1nos17,259.0016111,68,699.00
bComponent 2nos11,850.001612,97,850.00
Total Rate per Room9,109.00
Sub-Total14,66,549.00
Sr. No. column holds "1" for the header row and "a, b, c, d..." for sub-items. The header row's description is bold and spans the remaining columns (not confined to the Particulars column). "Total Rate per Room" sums the sub-items' individual rates. Ending "Sub-Total" row sums the Amount column only — never repeats the full section description.
